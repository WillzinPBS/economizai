# 🧩 Divisão de Tarefas — Front-End (Economizou)

## 📌 Objetivo

Organizar o desenvolvimento do front-end do projeto **Economizou**, dividindo as tarefas entre os membros da equipe de forma clara e eficiente.

---

## 👥 Estrutura do Time

- 👨‍💻 Desenvolvedores experientes (3)
- 🧑‍🎓 Iniciantes (4)

---

## 🗂️ Tarefas do Front-End

### 🟢 1. Estrutura das Páginas (HTML)

**Responsáveis:** Iniciantes  

Criar as páginas principais do sistema:

- `index.html` (Login)
- `cadastro.html`
- `dashboard.html`
- `produtos.html`

**Objetivo:**
Montar a estrutura básica das telas (sem lógica ainda).

---

### 🟢 2. Estilização com Tailwind

**Responsáveis:** Iniciantes  

Aplicar o design nas páginas:

- Layout responsivo
- Cores do projeto (verde, branco, amarelo)
- Botões, inputs e cards
- Espaçamentos e alinhamento

**Objetivo:**
Deixar o sistema visualmente agradável e moderno.

---

### 🟢 3. Componentes Reutilizáveis (UI)

**Responsáveis:** 1 Dev experiente  

Criar componentes reutilizáveis:

- Navbar
- Botões padrão
- Inputs
- Cards de produto
- Modal (login/feedback)

**Objetivo:**
Padronizar o visual do sistema.

---

### 🟢 4. Validação de Formulários

**Responsáveis:** 1 Dev experiente  

Implementar validações com JavaScript:

- Campos obrigatórios
- Tamanho de texto (nome, senha, login)
- Formato de telefone
- Confirmação de senha

**Objetivo:**
Garantir dados corretos e melhorar UX.

---

### 🟢 5. Integração com API (HTTP)

**Responsáveis:** 1 Dev experiente  

Implementar comunicação com o back-end:

- Requisições `GET` (buscar produtos)
- Requisições `POST` (login/cadastro)
- Tratamento de respostas da API

**Objetivo:**
Conectar o front-end com o sistema real.

---

### 🟢 6. Página de Produtos

**Responsáveis:** 1 iniciante + 1 experiente  

Implementar:

- Listagem de produtos
- Exibição de preços por mercado
- Destaque do menor preço

**Objetivo:**
Criar a principal funcionalidade do sistema.

---

### 🟢 7. Dashboard

**Responsáveis:** 1 iniciante + 1 Dev Experiente

Criar:

- Menu de navegação
- Exibição do usuário logado
- Links para outras páginas

**Objetivo:**
Centralizar a navegação do sistema.

---

### 🟢 8. Interações e Feedback (UX)

**Responsáveis:** 1 Dev experiente  

Implementar:

- Modais
- Mensagens de erro/sucesso
- Feedback visual (sem alert)

**Objetivo:**
Melhorar a experiência do usuário.

---

### 🟢 9. Responsividade

**Responsáveis:** Todos  

Garantir funcionamento em:

- Desktop
- Mobile

**Objetivo:**
Adaptar o layout para diferentes telas.

---

### 🟢 10. Testes

**Responsáveis:** Iniciantes  

Testar:

- Cadastro
- Login
- Navegação
- Integração com API

**Objetivo:**
Identificar erros e garantir funcionamento.

---

## 📅 Ordem de Execução

1. Estrutura HTML  
2. Estilização  
3. Componentes  
4. Validações  
5. Integração com API  
6. Produtos  
7. Dashboard  
8. UX  
9. Responsividade  
10. Testes  

---

## ⚠️ Regras do Projeto

- ❌ Não usar `alert`
- ✅ Usar feedback visual (modal/toast)
- ✅ Código organizado
- ✅ Seguir padrão do grupo
- ✅ Sempre testar antes de subir

---

## 🚀 Conclusão

A divisão de tarefas permite que todos os membros contribuam com o projeto, respeitando o nível de conhecimento de cada um e garantindo evolução do grupo como um todo.
